软件简介

一个程序覆盖“找书 → 读 → 听 → 译 → 整理 → 导出”的完整流程。下面这些功能都在当前版本里。

读

本地与网络阅读

txt、epub、mobi、html、md、fb2、rtf、pdf、chm、doc(x)、zip/rar/7z 打包小说；也支持网络书源与开源阅读 Legado 规则。

听

三种语音引擎

SAPI5（含第三方发音人）、微软自然语音（装适配器后自动出现）、本地克隆语音（用自己的声音朗读）。

译

离线翻译

本地模型中英互译，不依赖在线翻译；支持按段、整章、双语对照，译文有缓存。

扫

扫描版 PDF OCR

逐页识别扫描件，和文字层合并；首次识别慢一些，之后直接读缓存。

源

书源管理

导入、编辑、测试书源；支持百度/搜狗搜索、换源、章节更新与解析规则。

签

书签 / 文摘 / 高亮

列表分页、增删改查、跳转、批量删除与导出；正文右键即可添加。

屏

读屏与键盘

原生编辑控件、逐行朗读、无障碍名、Tab 焦点链、F7/F8、章节数字框 ↑↓ 与回车跳转。

备

数据与备份

SQLite 单文件数据库，自动每日备份；一键备份/恢复、存储空间清理、阅读统计。

i

详细使用说明

点击每一节的标题展开。读屏用户可以直接用标题导航（H 键）跳到需要的章节。

1. 安装、首次启动与卸载

安装（绿色版）

  1. 把 XinYue.zip 解压到一个固定目录，例如 D:\XinYueReader。不要放在桌面、下载目录或临时目录，升级时容易被清理。
  2. 双击 XinYueReader.exe。程序是 64 位，需要 .NET Framework 4.7.2（Windows 10 1803+ / Windows 11 通常自带；Win7/8 需要先安装运行库）。
  3. 如果 Windows 弹出 SmartScreen“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。程序未做商业代码签名，这是正常提示；请用上面的 MD5 确认文件完整。

首次启动

  • 程序会在 文档\XinYueConfig\ 建立数据库和配置；如果你的“文档”被重定向（例如 D 盘），数据就在那个位置。
  • 启动后会自动打开上次阅读的书和章节；焦点会尽量落到阅读框。若焦点不在阅读框，按 Tab 或点击正文即可。
  • 程序是单实例：已经在运行时再次双击，只会把已有窗口叫出来，不会开第二个。

卸载

  • 关闭程序，删除程序目录即可。若要彻底清除数据，再删除 文档\XinYueConfig\（删除后书架、书签、文摘、阅读进度都会消失，请先备份）。
2. 主界面：8 个选项卡

主界面用选项卡组织，Ctrl+1…8 可直接切换，Ctrl+Tab / Ctrl+Shift+Tab 循环切换。

选项卡用途
阅读正文、书签侧栏、章节目录、上一章/下一章/跳转、字号与排版。
书库按书源搜索网络小说、查看分类、解析章节、打开网络小说。
书架已收藏的书；可导入本地图书、打开章节、删除、批量管理。
最近阅读按阅读时间排序，回车继续上次的章节和光标位置。
文摘摘录列表，分页展示，支持增删改查和导出。
书签书签列表，支持跳转、删除、批量操作。
翻译整段/整章翻译、双语对照、翻译缓存。
设置常规、语音、阅读排版、快捷键、模型管理等。
3. 打开本地小说
  • 主菜单 文件 → 打开，选择 txt / epub / mobi / html / md / fb2 / rtf / pdf / chm / doc(x) / zip / rar / 7z 等文件。
  • 批量加书：在书架的图书列表里右键 → 导入，可一次选多个文件。导入后会解析目录并加入书架。
  • 压缩包小说会先解压/读取内部文本；PDF 若没有文字层，程序会提示或自动走本地 OCR（见第 8 节）。
  • txt 编码识别失败出现乱码时，换一个编码正确的版本，或在书架里重新导入；程序会尽量自动识别 UTF-8 / GBK。
4. 打开网络小说、书库与书源

从网址打开

  1. 主菜单 文件 → 打开网络小说。
  2. 填写书名、目录页网址，选择图书类型，点确定。
  3. 程序会解析章节；成功后焦点会到章节列表，选一章即可开始阅读，并把书加入书架。
  4. 解析失败时会提示原因；可以检查网址是否是目录页、站点是否需要验证码，或换一个书源。

在书库里搜索

  • 书库选项卡选择书源（百度搜索 / 搜狗搜索 / 自定义书源），输入关键词搜索。
  • 百度/搜狗搜索会调用内置浏览器；如果出现验证码，请先在浏览器里完成验证，再回到程序重试。
  • 支持导入开源阅读（Legado）书源：书库 → 管理书源 → 导入；导入后可测试、编辑、启用/停用。
  • 读到一半发现书源失效，可用 换源（默认 Ctrl+Win+Alt+F）从其他书源继续。
5. 阅读操作：翻章、跳转、查找、排版
  • F7 打开/收起章节列表；F8 打开/收起书签列表。焦点在阅读区时也有效。
  • 底部“第 N 章，共 M 章”数字框：↑ 值 +1、↓ 值 −1，Enter 跳转。
  • 上一章 / 下一章 / 跳转按钮；加载期间按钮会自动禁用，避免连点。
  • 阅读区按 Tab：优先跳到“下一章”按钮；没有下一章时跳到选项卡表头。Shift+Tab 反向。
  • 右键正文：开始/暂停/停止朗读、添加书签、添加文摘、过滤本段、查词典、高亮、全选、复制。
  • 正文内查找：按用户要求主界面没有单独的查找框；可使用读屏软件自带的查找功能，或通过 F7 章节目录定位。
  • 排版：设置 → 阅读设置可调字体、字号、加粗、行距、段距、首行缩进、页边距、自动换行；也可用工具菜单的自动滚动和朗读定时。
  • 从书架/书库/最近阅读打开图书时，会回到上次阅读的章节和光标位置；在章节列表里明确选另一章则从该章开头读。
6. 语音朗读：SAPI5、自然语音、本地克隆

选择引擎

打开 设置 → 语音设置，在“语音引擎”里选择：

  • SAPI5.0：系统自带语音（如慧慧、Zira），也支持第三方 SAPI5 发音人。右侧“语音角色”列出系统里所有可用角色。
  • 微软自然语音：需要先安装 NaturalVoiceSAPIAdapter。设置页有“安装自然语音(_V)”一键安装；装完重启程序。它会把 Windows 讲述人的自然语音（晓晓、云希、Aria 等）和 Edge 在线语音暴露给 SAPI5。
  • 本地克隆语音：先在模型管理里下载 GPT-SoVITS 引擎，再选择 5 秒~1 分钟的参考音频（说 10 字以上中文最好）。适合想用自己的声音朗读的用户。

朗读操作

  • 默认 Ctrl+Win+Alt+S 开始/停止朗读；Ctrl+Win+Alt+P 暂停/继续。可在设置 → 快捷键里改成全局或程序内。
  • 朗读时按“段”推进：程序会把正文合并成约 150 字的段，整段合成后连续播放，减少段与段之间的空档。
  • 试听：在语音设置里点“试听”，确认发音人、语速、音量正常后再开始朗读。
  • 读屏逐行朗读：关闭数字键（NumLock 关），按小键盘 7；光标在哪就从哪开始，读完一行继续下一行。
  • 睡眠定时 / 读完本章停止：在工具菜单里设置，适合睡前听书。

合成到文件

  • 工具 → 合成语音：把一章合成一个 wav；合成全本小说：合并 txt 或逐章 wav，可续跑、失败重试。
  • 自然语音取决于所选角色：Edge 在线语音需要联网，Narrator 本地语音不需要；本地克隆和 SAPI5 可离线。
7. 翻译：本地模型中英互译
  • 先在 工具 → 模型管理 下载翻译模型（中译英 / 英译中，opus-mt）。模型完全在本地运行，不上传正文。
  • 没下载模型就使用翻译，程序会提示你先下载，不会静默失败。
  • 翻译方式：翻译选中文本（默认 Ctrl+Win+Alt+Q）、翻译当前段落（Ctrl+Win+Alt+T）、整章翻译。
  • 设置里可开“双语对照”：上行原文、下行译文；后台会预取下一章的翻译，读完一章后切换更快。
  • 译文有缓存，同一段第二次翻译基本是瞬时的。
8. 扫描版 PDF 的本地 OCR
  • 打开没有文字层的扫描版 PDF 时，程序会逐页判断：某页文字太少或像乱码，就只对那一页做 OCR，再和文字层合并。
  • OCR 使用本地 Tesseract 5（随程序提供），不需要联网，也不上传文件。
  • 第一次识别会慢一些；结果会缓存为 <原文件名>.ocr.txt，下次打开直接读缓存。
  • 识别质量取决于扫描清晰度；倾斜、低分辨率、手写体的效果会差一些。
9. 书签、文摘、高亮、词典与过滤词
  • 书签：阅读区右键“添加书签”，或按 F8 打开书签列表；列表支持分页、跳转、删除。
  • 文摘：选中文字后右键“添加文摘”；文摘选项卡支持增删改查、分页和导出 txt。
  • 高亮：选中文字右键“高亮”，可在“高亮笔记”里查看；支持清除本章高亮。
  • 查词典 / 生词本：选中文字右键查词典（默认 Ctrl+Win+Alt+D），生词本默认 Ctrl+Win+Alt+V。
  • 过滤词：右键“过滤本段文字”可把广告/站点声明加入过滤规则；以 ## 开头可写正则。
10. 数据、备份、恢复与迁移

所有用户数据都在 “文档”目录下的 XinYueConfig（如果“文档”被重定向，就在重定向后的位置）。常见文件：

  • YGBH.DB：SQLite 数据库，书架、书签、文摘、阅读位置、书源等。
  • option.xml：设置、快捷键、语音参数。
  • BookSources.json / BooksSpider.xml：书源配置。
  • Backup\：自动/手动备份；log.txt / trace.txt：日志与排错轨迹。
  • Speak\、XinYueDownload\、XinYueVoiceSynthesis\：语音、下载、合成缓存。

备份：文件 → 工具 → 数据备份；程序默认每天自动备份一份。

恢复：选好备份后，按提示关闭程序再重新打开，才会真正换回数据；当前数据会先自动备份一份。

迁移到新电脑：复制整个程序目录 + XinYueConfig 目录；不要只复制 exe。

11. 检查更新与手动升级
  • 程序启动时会静默检查更新；有新版本会提示。也可以手动执行 文件/帮助 → 检查更新。
  • 更新读取 UpdateInfo.json（版本号、更新说明、安装包 MD5），下载后由升级器覆盖程序文件。
  • 升级不会动 XinYueConfig，书架和阅读进度会保留。
  • 如果自动更新失败：下载最新的 XinYue.zip，解压后覆盖程序目录（保留 XinYueConfig 不动）即可。

常见问题

先看这里；仍然解决不了，把 trace.txt 最后几十行发给作者最快。

双击 exe 没反应 / 一闪而过
先确认托盘里是否已经有“新阅”（单实例，重复启动只会激活旧窗口）。没有的话，检查是否缺少 .NET Framework 4.7.2、是否被杀毒软件拦截；再查看 文档\XinYueConfig\trace.txt 最后几行。
Windows 提示“已保护你的电脑”
程序没有购买商业代码签名证书，SmartScreen 会对新 exe 提示。点“更多信息 → 仍要运行”，并用页面上的 MD5 核对文件。不要从不明来源下载。
打开书后没有声音
先到设置 → 语音设置点“试听”：没声音就换发音人/引擎；自然语音需要联网（Edge 在线）并装好适配器；本地克隆需要先启动模型服务。再检查系统音量、输出设备、程序音量。
语音引擎里没有“微软自然语音”
需要安装 64 位的 NaturalVoiceSAPIAdapter，并在安装器里勾选 Narrator 本地语音 / Edge 在线语音；装完重启本程序。Windows 11 还要先在“讲述人”里下载自然语音包。
翻译提示“未下载模型”
打开 工具 → 模型管理，下载中译英 / 英译中模型。模型是本地文件，下载一次即可离线使用；程序会先检查磁盘和硬件。
网络小说解析不出章节
确认填的是“目录页”而不是某一章；有些站点需要验证码或对爬虫有限制，可以在书库里换一个书源，或稍后重试。解析成功后程序会自动加入书架。
扫描版 PDF 识别很慢 / 识别不出来
第一次打开要逐页 OCR，页数多时会慢；现在翻到哪一页就即时识别哪一页（约 1 秒），后台也会继续逐页补全，不用重新打开。之后会读 <文件名>.ocr.txt 缓存。扫描太模糊、倾斜严重或手写体时，识别率会下降。
读屏在阅读区里不能逐行朗读
阅读区是原生编辑控件，需要它自己有光标焦点。点一下正文，或按 Tab 把焦点移回阅读框；数字键关闭时按小键盘 7 开始逐行朗读。若焦点被侧栏抢走，按 F7 收起章节列表。
数据在哪？换电脑怎么迁移？
在 文档\XinYueConfig\。迁移时复制整个程序目录和这个配置目录；不要只复制 exe，否则书架和设置会丢。
GitHub 下载很慢 / 打不开
用页面上的 GitHub Raw / 仓库直链 / ghfast 镜像；它们指向同一个文件，MD5 应一致。
