新阅阅读器（XinYueReader）

面向 Windows 的桌面小说阅读器，朗读 / 翻译 / 书源 / 书架书签文摘一体，64 位，需 .NET Framework 4.5 或更高。

当前版本：V2.0.4.8（2026-10-16）

⬇ 下载新阅阅读器 V2.0.4.8（约 23 MB）

怎么装

  • 把下载到的 XinYue.zip 解压到一个固定目录（比如 D:\XinYueReader，别放桌面/临时目录）。
  • 双击里面的 XinYueReader.exe 就能用；程序是单实例，重复双击只会把已有窗口叫出来。
  • 你的书架、书签、文摘、设置都放在 文档\XinYueConfig\，升级不会动它。
  • 升级：程序里 帮助 → 检查更新（或让它自己检查）。

本版更新（V2.0.4.8）

  • 修复：合成语音"丢开头几个字" —— 微软自然语音换发音人/语速后第一次合成会被截断（现在先热身、缓存作废、时长太短自动重试）； 本地克隆语音（GPT-SoVITS）每次合成有一半概率随机吞字，现在【合成】会复用你刚【试听】听到的那一份（先试听满意再合成即可）。
  • 新增：【合成语音】窗口的"合成状态"只读框，合完显示文件名、时长、有没有段落没合出来。
  • 修复：解压后按某些键弹"未将对象引用设置到对象的实例"（阅读框未就绪时的空引用）；升级器可以自我更新了。

版本信息 / 升级检查

程序"检查更新"读的就是 UpdateInfo.json（版本号 / 更新说明 / 安装包 MD5）。
