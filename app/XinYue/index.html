软件简介

一个程序覆盖“找书 → 读 → 听 → 译 → 整理 → 导出”的完整流程。下面这些功能都在当前版本里。

读

本地与网络阅读

txt、epub、mobi、html、md、fb2、rtf、pdf、chm、doc(x)、zip/rar/7z 打包小说；也支持网络书源与开源阅读 Legado 规则。

听

五种语音引擎

SAPI5（含第三方发音人）、微软自然语音、本地克隆语音（GPT-SoVITS）、Kokoro 本地语音（103 个音色，中英混读）、ZipVoice 克隆语音（5~10 秒录音即可克隆）；后两个模型在【模型管理】里按需下载。

译

离线翻译

本地模型中英互译，不依赖在线翻译；支持按段、整章、双语对照，译文有缓存。

扫

扫描版 PDF OCR

逐页识别扫描件，和文字层合并；首次识别慢一些，之后直接读缓存。

源

书源管理

导入、编辑、测试书源；支持百度/搜狗搜索、换源、章节更新与解析规则。

签

书签 / 文摘 / 高亮

列表分页、增删改查、跳转、批量删除与导出；正文右键即可添加。

屏

读屏与键盘

原生编辑控件、逐行朗读、无障碍名、Tab 焦点链、F7/F8、章节数字框 ↑↓ 与回车跳转。

备

数据与备份

SQLite 单文件数据库，自动每日备份；一键备份/恢复、存储空间清理、阅读统计。

i

纯绿色版：下载的是 zip 压缩包，解压到固定目录即可运行，没有安装程序。程序是单实例，重复双击只会把已有窗口叫出来。

详细使用说明

点击每一节的标题展开。读屏用户可以直接用标题导航（H 键）跳到需要的章节。

1. 安装、首次启动与卸载

运行环境

  • 本版是 64 位程序（Release\X64），需要 .NET Framework 4.7.2。Windows 10 1803 以上 / Windows 11 一般自带；Win7 / Win8 需要先装 4.7.2 运行库（不装的话双击 exe 会“一闪而过”或提示缺少 .NET）。
  • 不需要安装数据库、不需要联网也能读本地小说；联网只用于书库搜索、检查更新、Edge 在线语音。

安装（绿色版，解压即用）

  1. 把 XinYue.zip 解压到一个固定目录，例如 D:\XinYueReader。不要放在桌面、下载目录、临时目录或 C:\Program Files（没有写权限，升级/自愈会失败）。
  2. 确认解压出来的目录里有：XinYueReader.exe、Update\Update.exe、Resource\、一大堆 .dll。少了 Update\ 升级会失败。
  3. 双击 XinYueReader.exe。首次启动会：建数据库 → 检查更新 → 播放启动音效 → 打开上次阅读的书（首次没有则停在阅读页）。
  4. Windows 弹出 SmartScreen“Windows 已保护你的电脑”属正常（未做商业签名）：“更多信息 → 仍要运行”，并用本页 MD5 核对文件。
  5. 如果杀毒软件把 XinYueReader.exe 或 zdsr 目录拦了，把程序目录加进排除项；否则可能出现“读屏念不出正文”之类的怪现象。

首次启动你会看到

  • 主界面是 8 个选项卡（见第 2 节），默认停在“阅读”。
  • 数据目录建在 “文档” → XinYueConfig（“文档”被重定向到 D 盘时就在 D 盘），见第 10 节。
  • 右下角/托盘出现“新阅”图标。点窗口右上角 × 只是隐藏到托盘，程序还在跑（朗读/自动翻章会继续）。
  • 真正退出：托盘图标右键 →“退出(E)”，或按已设的“退出程序”快捷键（默认 Ctrl+Win+Alt+Esc）。
  • 程序是单实例：已在运行时再双击 exe，只会把已有窗口叫到前台，不会开第二个；所以“双击没反应”先看托盘。

卸载 / 重置

  • 卸载：退出程序（托盘 → 退出）→ 删除程序目录。
  • 重置设置但保留书：只删 文档\XinYueConfig\option.xml。
  • 彻底清空：再删 文档\XinYueConfig\（书架、书签、文摘、阅读进度、书源全部消失，请先备份，见第 10 节）。
2. 主界面：8 个选项卡

切换方式：Ctrl+1…8 直选；Ctrl+Tab / Ctrl+Shift+Tab 循环；焦点在选项卡表头时用 ← / → 换页，Tab 进入该页内容。

选项卡里面有什么 / 怎么用
阅读左侧书签卡片（可隐藏）、中间正文、右侧章节卡片（可隐藏）、底部翻页栏（上一章 / 第 N 章数字框 / 跳转 / 下一章）。打开书、换章之后焦点会自动回到正文。
书库选书源 → 输入书名搜索 → 结果列表里回车打开；支持“搜索并解析章节”“管理书源”“导入开源阅读书源”。
书架已收藏的书。回车打开（回到上次章节与光标），右键导入/删除/查看信息；列表支持分页。
最近阅读按阅读时间倒序，最多显示 最近 20 本；回车继续上次的位置。
文摘摘录列表，分页；支持新增、修改、删除、导出。
书签当前书的书签列表，分页；支持跳转、删除；“添加书签”复用阅读区右键那套动作。
翻译输入/粘贴文本翻译、整段翻译、双语对照；模型在本地跑（见第 7 节）。
设置常规、语音、阅读排版、快捷键、模型管理、PDF 识别引擎。改完立刻生效，不需要重启。

提示：从书库 / 书架 / 最近阅读打开图书或章节后，程序会自动切到“阅读”页并把焦点放进正文，可直接按 7（读屏）或 ↑/↓ 开始读。

3. 打开本地小说

支持格式

  • 纯文本：txt（自动识别 UTF-8 / GBK / UTF-16）；
  • 电子书：epub、mobi、azw3、fb2、html/htm、md、rtf；
  • 办公文档：doc、docx、pdf（有文字层的直接读；扫描版见第 8 节）；
  • 压缩包：zip、rar、7z（内部单个 txt/html 自动取出）；
  • 其它：chm、umd 等（取不到正文时会提示）。

三种打开方式

  1. 文件 → 打开：选单个文件，直接读，同时加入书架。
  2. 书架 → 右键 → 导入：一次选多个文件批量导入，导入后统一解析目录。
  3. 命令行：XinYueReader.exe "D:\书\某本书.txt"（程序已在运行时会把窗口叫出来并打开这本书）。

目录（章节）是怎么来的

  • txt/epub 优先用文件自带目录；txt 没有目录时按“第X章 / 第X节 / 楔子 / 序章”等规则切分。
  • 规则都不匹配时走“通用启发式”：没有识别出目录的书会按每 3000 字左右自动切块，保证能翻页。
  • 章节数不对（太少/太多）时：换一个带目录的版本，或用 工具 → 格式转换 重新生成，再重新导入。

常见问题

  • 乱码：换一个编码正确的文件；程序会尽量猜，但 GB18030 之外的冷门编码可能猜错。
  • 扫描版 PDF：没有文字层的页面会自动走本地 OCR（第 8 节），可用 文件 → 保存为 TXT 把识别结果导出。
  • 打不开/提示格式不支持：先用别的阅读器确认文件本身没坏；仍不行就把文件名和提示文字发给作者。
4. 打开网络小说、书库与书源

方式一：文件 → 打开网络小说

  1. 填书名（用于书架显示）、目录页网址（注意：是“目录/章节目录”页，不是某一章的正文页）、选图书类型。
  2. 确定后程序解析章节；成功会自动加入书架、焦点跳到章节列表，选一章即可开始读。
  3. 失败会提示原因（不是目录页 / 需要验证码 / 没有匹配规则）。可换一个目录页网址，或改用书库搜索。

方式二：书库搜索

  • 书库 → 选书源 → 输入书名 → 搜索。内置“百度搜索 / 搜狗搜索”，也支持自定义与导入的 Legado 书源。
  • 百度走的是高级搜索（书名放“完整关键词”，不手工拼 site:、-新闻 这类运算符）；结果不足 5 条时会自动换说法再搜（全文阅读 → 最新章节 → 无弹窗）。
  • 结果里的视频、AI 智能回答、百科、问答、站点搜索页会被自动过滤掉，尽量只留“能读的书页”。
  • 出现验证码：程序会改用内置浏览器（Chromium）打开，你在里面手动过验证，再回程序重试。频繁触发就隔几分钟、或换搜狗/别的书源。
  • 选中一本书可以“搜索并解析章节”：直接拿到章节表并加入书架（这一步比较贵，只在你按的时候做）。

书源管理

  • 书库 → 管理书源：可新增、编辑、测试、启用/停用、删除、导入/导出。
  • 支持开源阅读（Legado）书源的解析规则：导入 json 后填好站点地址即可；规则里的 CSS 选择器 / 正则都能用。
  • 某个书源突然失效（站点改版、被墙）：用 换源（默认 Ctrl+Win+Alt+F）在同一本书上换一个书源继续读，阅读进度会按章节名对齐。

缓存与预取

  • 读到某一章时，后台会预取后面 5 章正文（间隔约 12 秒），翻下一章基本不用等。
  • 读屏逐行朗读时如果“读到章尾自动翻章”没触发，先确认设置里“自动翻页”是开着的（默认开）。
  • 章节正文取不到（站点需要登录/验证码/正文在图片里）时会重试几次，仍失败就提示；这类站点建议换源。
5. 阅读操作：翻章、跳转、查找、排版

翻章

  • 底部翻页栏：上一章 / 下一章 / 跳转；正在加载章节数据时这三个按钮会自动禁用，避免连点导致错乱。
  • 第 N 章，共 M 章数字框：↑ 值 +1、↓ 值 −1（只改数字，不跳），Enter 才跳转。直接键入数字会整体替换旧值。
  • F7 打开/收起章节列表（左侧），在列表里回车即打开该章；F8 同理是书签列表。
  • 自动翻页（设置 → 阅读设置，默认开）：光标停在最后一行（或最后一行行首不动一会儿）会自动进下一章；读屏逐行朗读就靠它连续读下去。
  • 自动滚动（工具 → 自动滚动）：每 N 秒往下滚一行，可设“到本章末尾就停”或继续滚下一章。

跳转与查找

  • 章节目录里的页码框同样支持 ↑/↓ 改页码、Enter 跳页（书库、书架、书签列表的分页框也一样）。
  • 主界面没有单独的“查找框”（按你的要求去掉了）：查找请用读屏软件自带的查找，或 F7 在目录里定位。
  • 书签 / 高亮笔记里的“跳转”会把光标放回保存的位置，并自动切回“阅读”页。

键盘顺序（焦点链）

阅读页里 Tab 的顺序是：正文 → 下一章 → 章节数字框 → 跳转 → 选项卡表头 → 正文；Shift+Tab 反向。没有“下一章”时（最后一章等）直接从正文落到表头。

右键菜单（在正文里按右键 / 读屏的上下文菜单键）

  • 开始朗读 / 暂停朗读（继续朗读）/ 停止朗读；
  • 添加书签、添加文摘、过滤本段文字（过滤词支持 ## 开头的正则）；
  • 查词典、高亮、清除本章高亮、全选、复制。

阅读进度

  • 每 60 秒自动保存一次（也保存在退出/关窗口时）；重开这本书会回到上次的章节和光标位置。
  • 在章节列表里明确选了另一章，就从那一章开头读；同一章则沿用上次位置。
  • “最近阅读”按阅读时间排序，最多显示最近 20 本。

排版与字体

  • 设置 → 阅读设置：字体、字号、加粗、行距（1~2 倍）、段间距、首行缩进、页边距、自动换行、翻页动画。
  • 改完立刻生效，不用重启；关掉“自动换行”时一行就是一段（适合横向滚动着读）。
  • 翻页动画对读屏用户会自动跳过（避免遮罩挡住朗读），也可以在设置里直接关掉。
6. 语音朗读：SAPI5、自然语音、本地模型

先选引擎（设置 → 语音设置）

引擎适合谁 / 需要什么是否联网
SAPI5.0首选、最省事：用系统里的发音人（慧慧、Zira，以及你装过的第三方 SAPI5 发音人）。离线
微软自然语音想听“晓晓/云希”这类自然语音：需要装 NaturalVoiceSAPIAdapter（设置页有一键安装）。Narrator 本地语音离线可用；Edge 在线语音需要联网。部分
本地克隆语音 / Kokoro / ZipVoice想用自己的声音或更好的本地模型：先在工具 → 模型管理下载，克隆语音还要选 5 秒~1 分钟的参考音频（说 10 字以上中文最好）。离线（首次下载要网）

发音人与音色参数

  • “语音角色”下拉框会列出当前引擎可用的发音人；选什么就用什么（不会偷偷换别的）。
  • 语速 / 音量 / 音高：滑块调节；“输出设备”可以指定用哪个声卡/耳机（不跟随系统默认）。
  • 左侧有个“试听”按钮：先用一句话确认音色与音量，再开始读整章。试听用的是当前所选角色。

朗读操作

  • 开始/停止：默认 Ctrl+Win+Alt+S；暂停/继续：Ctrl+Win+Alt+P（都可在设置 → 快捷键里改成全局或仅程序内）。
  • 朗读从当前光标位置开始，逐段推进（程序会把正文按句号/逗号拆成合适的段再合成，减少卡顿）。
  • 读完本章会自动读下一章；想只读一章就停：勾“读完本章就停”。
  • 睡眠定时：工具 → 朗读定时（例如 30 分钟），到点自动停止。
  • 朗读时阅读框光标会跟着走，方便你随时接着看；暂停只是暂时不出声，停止才是结束本次朗读。

合成到文件

  • 工具 → 合成语音：把当前章合成为 wav；合成全本小说：整本逐章合成，可续跑、失败重试。
  • 合成用的引擎/发音人与“语音设置”里选的一致；本地模型合成更慢但可离线。

没声音怎么查

  1. 先在语音设置里点试听：没声音 → 换发音人 / 换引擎 / 换输出设备；
  2. 自然语音：确认适配器已安装、角色是“Microsoft 晓晓/云希”这类；Edge 在线语音要联网，网络差会失败并提示；
  3. 本地克隆：确认模型已下载、参考音频能播放、参考文本与音频内容一致（不一致会念错或只念几个字）；
  4. 都不行就看 文档\XinYueConfig\log.txt 的最后几行（会写清楚是哪个引擎、什么错误）。
7. 翻译：本地模型中英互译
  • 先到 工具 → 模型管理 下载“中译英 / 英译中”模型（opus-mt），下载一次即可离线使用；没下载就用翻译，程序会提示你先下载，不会静默失败。
  • 三种用法：翻译选中文本（默认 Ctrl+Win+Alt+Q）、翻译当前段落（Ctrl+Win+Alt+T）、翻译选项卡里对话式翻译。
  • 双语对照（设置里开）：正文上行原文、下行译文；后台线程会预取下一章并翻译，读起来更连贯。
  • 译文有缓存：同一段第二次翻译基本瞬时；模型完全在本地跑，正文不会上传。
  • 机器翻译质量有限，长句/古风/专有名词容易别扭；要更准就一次翻一小段。
8. 扫描版 PDF 的本地 OCR
  • 打开 PDF 时逐页检查：某一页文字太少或像乱码，就只对那一页做 OCR，再和文字层合并，所以“只有几页是扫描件”的 PDF 也能正常读。
  • 识别引擎二选一（设置 → 阅读设置 → PDF 识别）：Tesseract 5（随程序提供）或 微软 OCR（Windows 10/11 自带，需要装 OCR 语言包）。换引擎后各自的缓存独立。
  • 一般“翻到哪页先识别哪页”（约 1 秒/页），后台继续补全；页数多时第一次打开会慢。
  • 结果缓存为 <原文件名>.ocr.txt，下次打开直接读；想重新识别就删掉这个文件。
  • 识别质量取决于扫描清晰度：倾斜、低分辨率、手写体、竖排古文会明显变差。
  • 可以把识别/合并后的正文用 文件 → 保存为 TXT 导出，当成普通小说再读。
9. 书签、文摘、高亮、词典与过滤词
  • 书签：正文右键“添加书签”，或 F8 打开列表；列表分页、回车跳转、Delete 删除。书签按书保存，换书只显示当前书的。
  • 文摘：选中文字 → 右键“添加文摘”；“文摘”选项卡里可增删改查、分页、导出 txt。新文摘会带上书名与章节名。
  • 高亮：选中文字 → 右键“高亮”；“高亮笔记”里能看到全部高亮，可跳转；“清除本章高亮”一键恢复底色。
  • 查词典 / 生词本：选中文字右键查词典（Ctrl+Win+Alt+D）；查过的词进生词本（Ctrl+Win+Alt+V）。没有选区时取光标处的一个词（中文取 1~2 字）。
  • 过滤词：右键“过滤本段文字”把广告/站点声明加入规则，以后自动剔除；规则里以 ## 开头可写正则。改完重开本章即可看到效果。

11. 检查更新与手动升级
  • 启动时会静默检查更新，有新版本会提示；也可以手动“帮助/文件 → 检查更新”。
  • 更新信息来自 UpdateInfo.json（版本号、更新说明、安装包 MD5）；下载后由 Update\Update.exe 覆盖程序文件。
  • 升级不会动 XinYueConfig，书架与阅读进度都保留。
  • 自动更新失败：下载本页的 XinYue.zip，解压后覆盖程序目录（XinYueConfig 不动）即可；覆盖前先退出程序。
  • 核对完整性：certutil -hashfile XinYue.zip MD5 的结果应与本页显示的 MD5 一致。不一致就换镜像重下。
12. 读屏与纯键盘用户（重点）

阅读框的焦点

  • 正文是一个原生编辑控件，读屏的“逐行/逐字朗读”要求它自己有光标焦点。
  • 从书库 / 书架 / 最近阅读 / 章节列表打开书或章节后，程序会把焦点送进正文；如果听到的是按钮或列表，按 Esc 或 Tab 回到正文，或在正文上点一下。
  • 焦点在正文里时按 Tab：先到“下一章”按钮；没有下一章时到选项卡表头（再用 ←/→ 换页）。

争渡（ZDSR）常用操作

  • 关闭数字键（NumLock 关），按小键盘 7 = 逐行朗读：从光标所在行开始，一行一行往下读。
  • ←/→ = 逐字朗读；按住 Shift 再按 → = 选中并朗读选中的内容。
  • 读到本章最后一行会自动进下一章（前提：设置里“自动翻页”开着；这条在 V2.0.6.25 之前有两个 bug，已修）。
  • 程序自己的“朗读”和读屏的“逐行朗读”是两套东西：要读屏念，就别开程序的语音朗读；两者同时开会互相抢光标。

其它无障碍约定

  • 所有按钮都保留文字标签与访问键（如“下一章(_N)”），不用纯图标代替文字。
  • 章节数字框：↑/↓ 改值、Enter 跳转；改值时读屏只念一次新值。
  • 加载章节数据时，“上一章/下一章/跳转”会禁用，避免你在加载中连按。
  • 翻页动画检测到读屏会自动跳过，不会用遮罩挡住正文。

“读屏读不出正文”自查顺序

  1. 先看别的程序（记事本）里读屏能不能读：不能 → 读屏/系统/杀毒问题，不是本程序；
  2. 检查程序目录里有没有多余的 UIAutomation*.dll（会弹“未能从程序集 UIAutomationTypes…”）：新版启动会自动改名避开，重启一次即可；
  3. 确认正文有焦点（见上）；章节很短也可能“读到空行”是正常现象（空行就是没字）；
  4. 仍不行：把 文档\XinYueConfig\trace.txt 最后 30 行发给作者（里面有 `章尾光标判定`、`阅读排版 应用` 等关键行）。

常见问题

先看这里；仍然解决不了，把 trace.txt 最后几十行发给作者最快。

双击 exe 没反应 / 一闪而过
先确认托盘里是否已经有“新阅”（单实例，重复启动只会激活旧窗口）。没有的话，检查是否缺少 .NET Framework 4.7.2、是否被杀毒软件拦截；再查看 文档\XinYueConfig\trace.txt 最后几行。
Windows 提示“已保护你的电脑”
程序没有购买商业代码签名证书，SmartScreen 会对新 exe 提示。点“更多信息 → 仍要运行”，并用页面上的 MD5 核对文件。不要从不明来源下载。
打开书后没有声音
先到设置 → 语音设置点“试听”：没声音就换发音人/引擎；自然语音需要联网（Edge 在线）并装好适配器；本地克隆需要先启动模型服务。再检查系统音量、输出设备、程序音量。
语音引擎里没有“微软自然语音”
需要安装 64 位的 NaturalVoiceSAPIAdapter，并在安装器里勾选 Narrator 本地语音 / Edge 在线语音；装完重启本程序。Windows 11 还要先在“讲述人”里下载自然语音包。
翻译提示“未下载模型”
打开 工具 → 模型管理，下载中译英 / 英译中模型。模型是本地文件，下载一次即可离线使用；程序会先检查磁盘和硬件。
网络小说解析不出章节
确认填的是“目录页”而不是某一章；有些站点需要验证码或对爬虫有限制，可以在书库里换一个书源，或稍后重试。解析成功后程序会自动加入书架。
扫描版 PDF 识别很慢 / 识别不出来
第一次打开要逐页 OCR，页数多时会慢；现在翻到哪一页就即时识别哪一页（约 1 秒），后台也会继续逐页补全，不用重新打开。之后会读 <文件名>.ocr.txt 缓存。扫描太模糊、倾斜严重或手写体时，识别率会下降。中文印刷体想更准，可以在 设置 → 常规设置 → PDF 识别 里换成「PP-OCRv5 本地模型」（模型要去模型管理里下一份，见下一条）。
选了 PP-OCRv5，却提示“没有找到 PP-OCR 模型”
V2.0.6.28 起 PP-OCRv5 的 21MB 模型不再随程序发布。到 工具 → 模型管理，选「PP-OCRv5（扫描版 PDF 中文识别）」，按【安装/下载(_I)】等它下完（约 21MB，存到 文档\XinYueConfig\Models\ocr\ppocrv5）。下完不用重启，回到 设置 → 常规设置 → PDF 识别 选它即可；不想用时可以在模型管理里【删除(_D)】释放空间。模型缺失时程序会自动回退 Tesseract，不会打不开书。
读屏在阅读区里不能逐行朗读
阅读区是原生编辑控件，需要它自己有光标焦点。点一下正文，或按 Tab 把焦点移回阅读框；数字键关闭时按小键盘 7 开始逐行朗读。若焦点被侧栏抢走，按 F7 收起章节列表。
读屏读到本章最后一行不跳到下一章
先确认 设置 → 阅读设置 里“自动翻页”是开着的。V2.0.6.25 修了两个原因：① 按过“暂停朗读”（不是“停止”）之后，程序曾误以为还在朗读，于是把自动翻章整个关掉；② 阅读框里光标的位置和正文位置差一个数（每个换行差 1 个字），长章节时光标永远“到不了末尾”。请升级到 V2.0.6.25 或更新版本；旧版可以先按“停止朗读”再试。
一打开就弹“未能从程序集 UIAutomationTypes… 中加载类型 IRawElementProviderSimple”
程序目录里混进了不该随程序分发的 UIAutomation*.dll（这类程序集必须用系统自带的那份）。V2.0.6.25 起启动时会自动把这类文件改名避开（trace.txt 里会有“程序目录里发现多余的 …已改名避开”），重启一次即可；也可以手动删除程序目录里的 UIAutomationClient.dll / UIAutomationProvider.dll / UIAutomationTypes.dll。
数据在哪？换电脑怎么迁移？
在 文档\XinYueConfig\。迁移时复制整个程序目录和这个配置目录；不要只复制 exe，否则书架和设置会丢。
GitHub 下载很慢 / 打不开
用页面上的 GitHub Raw / 仓库直链 / ghfast 镜像；它们指向同一个文件，MD5 应一致。
